# ebloid-reskin

Кастомный рескин и модификация интерфейса для браузера Google Chrome.

## Как установить расширение в Google Chrome

Так как расширение устанавливается напрямую из исходного кода (в обход Chrome Web Store), процесс занимает всего пару минут.

### Шаг 1: Скачивание проекта с GitHub

Вы можете выбрать один из двух удобных способов:

* **Вариант А (Простой):** Нажмите на зелёную кнопку **Code** вверху этой страницы, выберите **Download ZIP** и распакуйте архив на свой компьютер.
* **Вариант Б (Для разработчиков):** Склонируйте репозиторий через терминал:
  ```bash
  git clone https://github.com
  ```

### Шаг 2: Включение режима разработчика в Chrome

1. Откройте браузер **Google Chrome**.
2. В адресную строку вставьте и перейдите по ссылке: `chrome://extensions/`
3. В правом верхнем углу экрана найдите тумблер **Режим разработчика** (Developer mode) и включите его.

### Шаг 3: Загрузка расширения

1. В левом верхнем углу нажмите на кнопку **Загрузить распакованное расширение** (Load unpacked).
2. В открывшемся окне выберите **папку с проектом** (ту, где лежит файл `manifest.json`).
3. Нажмите **Выбрать папку** (Open).

Готово! Расширение появится в списке установленных и сразу начнет работать.
